Orch.ai

See every coding session at once. Orch.ai reads your local Claude Code sessions and shows each worktree, session and subagent as one live graph, with context usage and status per node.

  • Watches sessions started anywhere: terminal, IDE or inside the app
  • Warns before a session's context runs out and helps hand work off
  • Runs on your machine. No server, no account of ours

Requires Claude Code, signed in with your own Claude account or API key. Usage is billed to you by Anthropic as normal.
